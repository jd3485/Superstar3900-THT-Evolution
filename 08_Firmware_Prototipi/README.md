# Controllo digitale tradizionale — eventuale

La radio resta **prevalentemente analogica**. È ammesso un controller THT semplice per memorie di canale, commutazione, visualizzazione o strumenti, se necessario e verificato; non introduce automaticamente DSP avanzato, Dual Watch, VOX o CTCSS/DCS.

**Nessun microcontrollore né firmware di destinazione è stato ancora selezionato.** Qualunque microcontrollore futuro dovrà essere acquistabile in package THT reale, oppure sostituito da logica tradizionale idonea.

Qualsiasi modello software in questa cartella è un modello e non prova hardware.
