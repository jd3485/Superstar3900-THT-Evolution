# V1.4 — foglio fisico candidato VCO Colpitts B + SN74AC14N PDIP14

Nuovo quarto foglio KiCad9 con 37 istanze THT: Q501/Q502 2N3904 TO92, D501 BB204G 3 pin a catodo comune pin2, L501 modello 166nH footprint **DA DECIDERE**, filtro R/C di V0.6, buffer U520 SN74AC14N con due invertitori, stadi non usati con ingressi a GND e uscite NC. Le connessioni VTUNE e LO sono gerarchiche reali; separate alimentazioni esterne 5V VCO e 5V buffer. Validazione oscillazione/lock/accoppiamento/EMI non eseguita, no PCB. `node 04_KiCad/V1.4/genera_vco_lo_v14.js` rigenera sorgenti. NO FAB / NO TX.
